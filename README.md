# Intuitive Academy — Tutor Log

A phone web app for tutors to log lesson attendance. A tutor taps who attended; the session writes straight into a **formatted Google Sheets invoice in their own Google Drive**. No backend, no database, no spreadsheet the tutor has to touch.

**Live:** https://intuitive-tutor-log.pages.dev — used by every tutor at Intuitive Academy.

<br>

## Why it's built this way

- **No server, no database.** The app is static files on Cloudflare Pages. Each tutor's data lives in *their own* Google Sheet, in *their own* Drive — the app holds nothing.
- **Clean Google sign-in, no "unverified app" warning.** It uses only Google's **non-sensitive** scopes — `drive.file` (files this app creates) and `userinfo.email` — so the consent screen is the normal one. No verification review, no "Advanced → unsafe", no Apps Script `script.google.com` link.
- **The sheet format lives in code.** The invoice layout (crest, coloured tabs, per-student colours, cumulative hours, totals) is generated by the app via the Sheets REST API — every tutor gets an identical, correct invoice.
- **Safe writes.** Logging is idempotent (a receipt per operation survives a dropped connection without double-writing), guarded against two devices writing at once, and duplicate sessions are detected before they're saved.

## How it works

1. Tutor opens the link and signs in with Google (their own account).
2. First time: a quick setup (name, hourly rate, their groups/students) creates the invoice spreadsheet in their Drive.
3. Each lesson: tap the students who attended (or add a one-off), pick a date, **Log** → rows and running totals appear in the sheet.
4. End of month: a nudge offers a ready-to-send invoice email to the academy.

The config (roster, rate, theme) is stored in the spreadsheet's `developerMetadata`, so a tutor can recover their invoice on any device just by signing in — nothing is kept outside their Drive.

## Stack

- Vanilla JS (ES modules), no framework — fast on a phone.
- Google Identity Services (token model) + Google Sheets & Drive REST APIs.
- Cloudflare Pages (static hosting, free tier).
- Core logic is pure functions, tested with `node --test` against an in-memory Google double.

## Develop

```bash
npm install
npm test          # unit tests for the sheet builders, store, and invoice-email logic
npm run dev       # local preview on http://localhost:8787
```

To run your own instance you need one Google OAuth **web client ID** (non-sensitive scopes only) in `public/config.js`; `npm run deploy` publishes to Cloudflare Pages.

## Project layout

```
public/        the app (static)
  app.js         UI / interactions
  store.js       data layer — spreadsheet create/read/write over the Sheets API
  invoice.js     invoice sheet builders (layout, formulae, formatting)
  invoice-email.js  end-of-month invoice email
  google-api.js  Google auth + request transport
tests/         node --test suites + the in-memory Google double
scripts/       config check + local preview helpers
```
